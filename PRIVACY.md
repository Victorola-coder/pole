# Privacy Policy (Draft)

## Data Collection

Pole does not require account creation and does not send user files to external servers by default.

## Data Access

- Photos and videos are accessed only after explicit user permission.
- Files are accessed only for folders the user selects through the iOS Files picker.
- Access is stored using security-scoped bookmarks managed by iOS.

## Data Storage

- App preferences are stored in local `UserDefaults`.
- Deletion audit entries are stored locally on device in app support storage.

## Data Deletion

- Users can clear saved folder access in Settings.
- Users can clear local deletion audit logs in Settings.

## Third-Party Services

No third-party analytics or crash-reporting SDKs are enabled by default in this codebase.
